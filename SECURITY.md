# Security policy

This policy covers every repository in the [`thesaladetheory`](https://github.com/thesaladetheory) organisation and the services built from them.

## Reporting a vulnerability

Please **don't** report security issues in public issues, pull requests or discussions.

Report them privately through GitHub: [open a private vulnerability report](https://github.com/thesaladetheory/.github/security/advisories/new). Include:

- what is affected (repository, URL or app screen)
- steps to reproduce, or a proof of concept
- the impact you think it has

We'll acknowledge your report, keep you updated while we fix it, and credit you when it's published if you'd like.

## Please don't

- access, change or delete data that isn't yours
- run denial-of-service or load tests, or send spam
- use social engineering or test physical security

## Supported versions

Only the latest release of each service is supported.
